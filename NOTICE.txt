Tiny Swords RTS - Realm War is a local HTML5 top-down RTS built from the Tiny Swords free asset pack uploaded by the user.

Original asset pack: Tiny Swords by Pixel Frog.
Review the original itch.io page/license before redistributing or publishing.

Integrated hunting animal asset pack:
- assets/CraftPix Hunt Animals
- Source: user-provided CraftPix free top-down hunt animals pixel sprite pack.
- Only the runtime PNG sheets used by the game are bundled. Aseprite sources and unused pack contents are not bundled.
- See assets/CraftPix Hunt Animals/LICENSE.txt and https://craftpix.net/file-licenses/ before publishing.

Runtime architecture note:
The old runtime override module remains removed from the active project. Gameplay behavior lives in canonical domain files, especially js/systems/simulation.js, js/systems/input.js, js/ui/hud.js, and js/render/world-renderer.js.
