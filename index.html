Tiny Swords: Realm War

Top-down RTS. No hero unit: command workers, buildings, armies, towers and flags.

Camera
WASD / arrows pan, mouse edge pan, wheel zoom.
Select
Left click one thing, drag-select army, Shift adds. Drag your own buildings to relocate them.
Orders
Right click ground to move, resources to harvest, enemies to attack. Towers include their own archer.
Build
Press B, choose a building, left click to place. Workers must construct foundations.
Training
Select Castle/Barracks/Archery/Monastery, then use action buttons. Number keys recall control groups once saved.
Rally / Flag
Select a production building and right click ground to set its flag. New units walk there.
Towers
Each tower arrives with exactly one built-in archer. Select any unit or tower to preview range.
Minimap
Click to jump camera. Press M to expand/collapse.
Other
Ctrl+1-9 stores control groups, 1-9 recalls them, Ctrl+A selects army, 0 selects all units.
